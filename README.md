# HOME CREDIT LAP VOICE AGENT

## Project Overview

An AI-powered voice agent built using Retell AI for initial Home Credit Loan Against Property (LAP) eligibility screening.

## Objectives

* Conduct natural and professional customer conversations.
* Verify customer identity before proceeding.
* Evaluate customer eligibility using seven required checks.
* Handle disqualification politely.
* Manage busy customers and callback requests.
* Route existing property loan and loan-transfer queries to the appropriate specialist.
* Avoid inventing interest rates or guaranteeing loan approval.

## Technology Used

* Retell AI — voice agent creation and testing.
* Large Language Model — conversational reasoning.
* System prompting — conversation flow and eligibility rules.

## Eligibility Checks

1. Property type: residential, commercial, or industrial; agricultural property is ineligible.
2. Ownership: sole or joint ownership.
3. Availability of original property documents.
4. Loan amount up to ₹75 lakh, subject to customer acceptance of the maximum when applicable.
5. Salaried or self-employed occupation, with income received through a bank account.
6. Estimated current property market value.
7. Loan tenure between 3 and 15 years, inclusive.

## Key Features

* Natural conversational interactions.
* Eligibility screening and polite disqualification.
* Callback scheduling for busy customers.
* Handling answers provided out of order.
* Referral to a loan-transfer specialist when appropriate.
* Handoff to a senior loan expert for eligible customers.

The agent does not guarantee loan approval or provide unverified interest rates.
